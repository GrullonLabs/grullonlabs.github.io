# Logan Grullon — Cybersecurity Portfolio

Personal cybersecurity portfolio website.

## Purpose
This site is designed to showcase:
- Cybersecurity education
- Certifications
- Hands-on labs
- GitHub projects
- Technical skills
- Resume and professional links

## Customize before publishing
1. Replace `Loganluisg@gmail.com` in `index.html`.
2. Replace the GitHub and LinkedIn placeholder URLs.
3. Add your real `resume.pdf` to this folder.
4. Replace project placeholders with links to your repositories.
5. Add certifications as you earn them.

## Publish with GitHub Pages
1. Create a GitHub repository named `cybersecurity-portfolio` (or use `GrullonLabs.github.io` for a root site).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and your `resume.pdf`.
3. In GitHub: Settings → Pages.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you your live website URL.
